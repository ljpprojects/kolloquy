# Kolloquy

Kolloquy is (going?) to be a basic messaging app. It is (will be?) heavily
reliant on Cloudflare's network, which comes with its good parts and bad parts.

See the `docs` directory.

## What's with the long wait?

One would assume that in the time that has passed since the 23rd of May last
year the required upgrades would be done and Kolloquy up again. This is
obviously not the case, and it remains down still.

There is primarily one reason, and that is the existence of my other projects.
They, too, require maintenance, and are much more fun to work on than Kolloquy.

My hope is that once all the pieces start to come together, development should
be finished relatively soon after that point.
